# 服务器部署说明

本项目是纯静态网站：
- 无数据库
- 无后台服务
- 无 Node 生产进程
- 无 Redis
- 无 Docker 强制要求

推荐：Ubuntu + Nginx。

## 1. 本地测试

Windows 双击：

```text
start-local.bat
```

Linux / macOS：

```bash
./start-local.sh
```

访问：

```text
http://127.0.0.1:8899
```

本地服务器已支持：
- SPA 路由 fallback
- MP4 Range 请求
- 视频拖动进度

---

## 2. 推荐服务器目录

```text
/var/www/robot-showcase
```

第一次部署可以直接把项目运行文件同步进去：

```bash
python3 tools/build_content.py --dist /var/www/robot-showcase
```

会复制：

```text
index.html
assets/
data/site-data.json
data/contact-qr.png
content/
```

不会把 `_template` 发布到线上。

---

## 3. 安装 Nginx

```bash
sudo apt update
sudo apt install -y nginx python3
```

如需要视频尺寸自动检查：

```bash
sudo apt install -y ffmpeg
```

如需要图片尺寸检查和自动重新生成二维码：

```bash
pip install -r tools/requirements.txt
```

这些校验依赖都是可选的。

---

## 4. Nginx 配置

项目根目录已经提供：

```text
nginx.conf
```

可以复制：

```bash
sudo cp nginx.conf /etc/nginx/sites-available/robot-showcase
sudo ln -s /etc/nginx/sites-available/robot-showcase /etc/nginx/sites-enabled/robot-showcase
sudo nginx -t
sudo systemctl reload nginx
```

配置包含：
- `/category/...` SPA fallback 到 `index.html`
- `/content/` 7 天缓存
- `/data/site-data.json` 不缓存
- 普通 Nginx 静态文件响应，天然支持 MP4 Range 请求

站点没有“网页上传接口”，因此不需要配置 `client_max_body_size`。

---

## 5. 后续更新产品

你把新产品上传到源码目录：

```text
public/content/
```

然后：

```bash
python3 tools/build_content.py --dist /var/www/robot-showcase
```

刷新网页即可。

**不需要：**
- 重启服务器
- 重启 Nginx
- 重启数据库
- 重新安装依赖

---

## 6. 如果在本地维护，再上传服务器

本地：

```bash
python3 tools/build_content.py --dist deploy
```

会生成：

```text
deploy/
```

将这个目录上传到：

```text
/var/www/robot-showcase
```

即可。

---

## 7. 缓存说明

`site-data.json` 设置为 no-cache，所以新产品列表能快速更新。

媒体文件缓存 7 天。因此不要用同一个文件名替换完全不同的视频，推荐新增时改文件名，例如：

```text
01-动作展示-v2.mp4
```

这样可避免浏览器/CDN 保留旧视频。

---

## 8. OSS / CDN 后续升级

当前版本可以直接把媒体放服务器磁盘。

如果未来视频很多，可以把：

```text
/content/
```

迁移到阿里云 OSS / 腾讯云 COS + CDN。

届时只需要调整生成脚本中的媒体 URL 前缀，不需要重做网站页面结构。


## 视频首帧自动生图
如果大部分素材都是视频，可以直接让脚本从视频首帧自动生成图片：

- 输入：`public/content/<product-key>/videos/*.mp4`
- 输出：
  - `public/content/<product-key>/posters/<同名>.jpg`
  - `public/content/<product-key>/images/<同名>.jpg`

示例：

```text
videos/01-行走.mp4
=> posters/01-行走.jpg
=> images/01-行走.jpg
```

命令：

```bash
python tools/extract_video_stills.py
```

默认不覆盖已有图片；如需重建：

```bash
python tools/extract_video_stills.py --overwrite
```

只生成 poster：

```bash
python tools/extract_video_stills.py --only posters
```

只生成 image：

```bash
python tools/extract_video_stills.py --only images
```

`update-content.bat` / `update-content.sh` 已默认先执行这个步骤，再生成 `site-data.json`。


## Windows 视频工具初始化
视频首帧提取依赖 FFmpeg。Windows 第一次使用请先双击：

```text
setup-video-tools.bat
```

它会自动安装 `imageio-ffmpeg`，不要求配置系统 PATH。之后正常使用 `update-content.bat` 即可。

也支持把便携版 FFmpeg 放到 `tools/ffmpeg/bin/ffmpeg.exe`。
